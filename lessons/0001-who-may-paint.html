Who may paint?

Two images can contain the same pixels and still need independent answers to one question: may this result change my page now?

One result, two owners

The overhaul gives each image occurrence an ImageSession. Each session checks its current request, cancellation signal, attachment and source before accepting an asynchronous completion. Identical contents may reuse preparation through a separate cache. See the accepted decision.

Image A
Owns A's controls and overlay
Can retire without changing B
Image B
Owns B's controls and overlay
Checks its own current request
Shared preparation
OCR and translation can run once for equal content/settings. One consumer leaving does not stop work another consumer still needs.

Predict the next event

A and B share preparation. The page removes A while OCR is running. B remains attached with the same settings. OCR finishes successfully.

Cancellation has two jobs

Retire obsolete display authority immediately. Release a worker's capacity only when the actual work ends. Otherwise a cancelled request can still consume CPU while a replacement starts, defeating the concurrency limit. This distinction appears in the preparation cache and bounded execution modules.
