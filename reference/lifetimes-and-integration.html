Before changing a page

Current request? Current source/settings? Attached target? Still authorized? A completion is usable only after its owner checks these conditions. Read the repository decision and practice lesson.

Before integrating thermo

Review the exact clean candidate, pass its tests and CI, fetch the destination, and confirm ancestry. A fast-forward moves main along history already present in thermo; --ff-only refuses divergent histories. Git's primary reference.

git fetch origin
git log --oneline origin/main..thermo
git diff --stat origin/main...thermo
git merge-base --is-ancestor origin/main thermo

Inspect every exit status. The final switch/merge/push requires the full gates in the approved plan; these inspection commands alone do not establish readiness. Keep existing branch names unless cleanup is requested.
